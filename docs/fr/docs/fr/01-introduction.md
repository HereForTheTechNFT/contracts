# Hop Protocol : introduction

Hop est un pont inter-rollups pour déplacer rapidement des actifs entre Ethereum et plusieurs réseaux de couche 2. Le dépôt décrit les contrats qui coordonnent les bridges, les hTokens, les AMM et les bonders.

L’idée centrale est de distinguer l’actif canonique de sa représentation de pont : un hToken circule vite sur la couche 2, puis est échangé contre le token canonique local.

Ce parcours lit le code et la documentation présents dans ce fork. Aucune installation, compilation ou exécution n’a été effectuée.
